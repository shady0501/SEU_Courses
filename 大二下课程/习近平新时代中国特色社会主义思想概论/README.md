## 资料说明

### 复习资料

- `习概题目范围.docx`：汇总复习题目和考查范围。
- `习概题目范围-答案要点.docx`：按题目整理回答要点，适合在阅读教材后用于检查知识结构。

### 往年试题参考

`往年试题参考/` 中的 2023 年春季学期期末大作业 A 卷可用于了解当时的题目形式和作答要求。不同学期的考核方式可能变化，不应将单份往年材料视为固定题库。

## 建议使用顺序

1. 先浏览教材目录，了解课程整体结构。
2. 阅读题目范围，按主题在教材中定位对应章节。
3. 独立整理每道题的论述框架，再使用答案要点查漏补缺。
4. 最后查看往年期末大作业，练习围绕材料组织完整回答。

## 使用说明

- 复习资料和往年考核仅供学习参考，请以当学期课程安排和教师要求为准。
- 涉及理论概念和规范表述时，建议以正式教材及最新课程资料为依据。
- 习概也没什么好说的，老师一般都会划范围的，划好之后背就完了。

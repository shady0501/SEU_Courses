# 算法设计与分析课程资料

本目录收录算法设计与分析课程的课件、作业、上机实验、复习资料及往年试题。资料以 2024 年课程为主，覆盖算法复杂度、分治、动态规划、贪心、回溯与分支限界、排序及 NP 完全性等主题。

## 课程概览

| 项目 | 内容 |
| --- | --- |
| 课程课件 | 2024-Alg-L01—L16，共 16 讲，另有参考教材 |
| 课程作业 | 第 1—5 次作业、批改版、提交版及 LaTeX/Markdown 源文件 |
| 上机实验 | 8 次实验文档、实验流程说明及输入数据 |
| 复习资源 | 复习范围、个人笔记、习题整理和往年试题回忆 |

## 课件

`课件/` 中的 `2024-Alg-L01.pdf` 至 `2024-Alg-L16.pdf` 构成课程主体。结合复习资料，主要内容包括：

- 算法描述、正确性与时间空间复杂度；
- 渐进记号及递推式分析；
- 递归与分治算法；
- 动态规划的状态设计、转移方程与最优子结构；
- 贪心算法及其正确性证明；
- 回溯、分支限界与搜索空间；
- 排序算法及其性能分析；
- 可计算性、P、NP 与 NP 完全问题。

`参考教材-算法设计与分析.pdf` 可用于补充课件中的定义、证明和算法示例。

## 作业

`作业/` 保存第 1—5 次作业的多种版本：

- `第01次作业.pdf`—`第05次作业.pdf`：整理后的作业提交版；
- 对应的“批改版”：保留批阅或订正信息；
- `2024_as01.pdf`：课程作业说明或题目资料；
- `2024_hw01/`—`2024_hw05/`：Markdown、LaTeX、PDF 及插图等源文件。

阅读时建议先独立完成题目，再对照提交版和批改版。源文件适合继续修改、重新排版或追踪推导过程。

## 上机实验

`实验/` 包含 `2024_EX1.docx`、`2024_EX2.docx` 及 `2024-EX3.docx`—`2024-EX8.docx`，共 8 次实验文档；另有：

- `算法上机实验流程-2024.pdf`：说明实验流程、环境或提交要求；

## 建议

1. 学习复杂度分析和递推式，为后续算法比较建立统一方法。
2. 依次掌握分治、动态规划、贪心和搜索类算法，并为每种方法总结适用条件。
3. 每学完一个专题完成对应作业和上机实验，重点检查正确性证明与复杂度。
4. 使用批改版订正容易遗漏的推导步骤。
5. 按复习范围整理模板题，再使用往年回忆题和 A 卷图片进行综合练习。

## 说明

- 个人笔记、试题回忆和批改版中的内容仅供参考，使用时应结合课件核对。
- 年份不明的试卷保留“未知年份”标识，以避免误导。
- 不同学年的教学内容和实验要求可能调整，请以当学期要求为准。
- 算法在当年考试较难，均分也就七十多，难度是动态变化的，下一届的貌似就简单了；实验的时候尽量老老实实做题，课后有机会多刷刷洛谷/力扣的课内学过的算法类型的题，这样才能够在面对期末考试时游刃有余。

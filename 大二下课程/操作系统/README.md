# 操作系统课程资料

本目录收录操作系统课程的课件、复习资料、实验文件及往年试题。课程以 `Operating System Concepts` 为主要参考，覆盖进程与线程、处理器调度、同步与死锁、内存与虚拟内存、磁盘、文件系统和 I/O 等主题。

## 课程概览

| 项目 | 内容 |
| --- | --- |
| 课程资料 | 教学安排、考核标准、英文教材及第 0—10 章课件 |
| 实验内容 | 必做实验：Reverse、xv6 系统调用；选做实验：xv6 虚拟内存 |
| 复习资源 | 复习课件、同步习题、信号量参考读物及多学年试题 |

## 课件内容

课件主体按 `Operating System Concepts` 的章节组织：

| 章节 | 主要内容 |
| --- | --- |
| CH00—CH02 | 课程导论、操作系统功能、系统调用与操作系统结构 |
| CH03—CH04 | 进程、进程通信、线程与多线程模型 |
| CH05 | CPU 调度、调度准则和常见调度算法 |
| CH06 | 临界区、互斥锁、信号量、经典同步问题与管程 |
| CH07 | 死锁条件、预防、避免、检测与恢复 |
| CH08—CH09 | 主存管理、分页、页表、请求分页、页面置换与抖动 |
| CH10 | 磁盘结构、磁盘调度和 RAID |

`OSC___SCHEDULE.pdf` 给出了完整教学进度，其中还列出文件系统和 I/O 系统等后续主题；`Evaluation_Standards__CN_.pdf` 与英文版本说明课程考核构成。

## 实验

### 必做实验

- `Reverse/`：保存 `main.c`，实现文件内容反转等基础 C 语言与文件操作练习。
- `Xv6-Syscall/`：保存 `syscall.c`、`syscall.h`、`sysfile.c`、`user.h` 和 `usys.S`，对应 xv6 系统调用的添加或修改。
- `Guide_to_Xv6_Labworks.pdf`：xv6 实验指导。
- `操作系统必做实验报告.pdf`：汇总必做实验的实现过程和结果。

### 选做实验

`选做实验/Xv6-Virtual-Memory/` 保存虚拟内存主题的实验报告和展示 PPT，重点涉及 xv6 的地址空间、页表及相关内存管理机制。

## 复习资料

- `操作系统复习课1.pptx`、`操作系统复习课2.pptx`：用于期末知识点梳理。
- `进程同步习题课.ppt`：集中练习进程同步、信号量和经典同步问题。
- `OPERATING_SYSTEM_CONCEPTS___The_Little_Book_of_Semaphores.pdf`：信号量与同步问题的补充读物。

## 往年试题

`往年试题参考/` 收录较早试卷、近年试题回忆、期中材料、考研真题。资料形式和完整度不一，部分只有题目或回忆内容，部分带有答案或手写标注。

建议优先使用：

1. 较新的期中试题与回忆资料，用于了解当前题型；
2. `东南大学操作系统试卷集.pdf`，用于集中练习；
3. `期中复习题.pdf` 和复习课件，用于专题查漏；
4. 较早试卷及考研题，用于补充算法计算和概念辨析。

## 建议

1. 按 CH01—CH04 建立系统结构、进程和线程的基础概念。
2. 学习 CPU 调度，并通过甘特图练习等待时间和周转时间计算。
3. 集中掌握同步、信号量和死锁，这些主题适合结合习题反复推演。
4. 学习主存与虚拟内存，重点理解地址转换、页面置换和缺页过程。
5. 完成必做实验，将系统调用和虚拟内存概念对应到 xv6 源码。
6. 使用复习课件和近年试题检验知识，再用较早试卷补充练习。

## 说明

- 往年试题、回忆题和手写答案可能不完整或存在误差，请结合课件核对。
- xv6 不同版本的源码结构可能有差异，复现实验时应先确认实验指导所对应的版本。
- 教学范围和考核方式可能调整，请以当学期发布的要求为准。
- 操作系统知识点比较琐碎，也不是很简单，建议多复习巩固，多刷题。

# 软件工程导论课程资料

本目录收录软件工程导论课程的课件、作业、课程实验、复习资料及往年试题。课程内容覆盖软件过程、敏捷开发、需求工程、分析与设计、软件架构、测试、配置管理、项目管理、度量估算和风险分析。

## 课件内容

### Part 0：软件工程基础

介绍软件的本质、软件工程的产生背景、基本概念、课程结构和主要目标。

### Part 1：软件过程与人员

包括软件过程结构、过程模型、敏捷开发、DevOps 及软件工程中的人员因素。

### Part 2：需求、分析与设计

涵盖需求理解、基于场景和类的分析方法、行为建模、设计模式、设计概念、架构设计、构件设计及用户界面设计。

### Part 3：质量与配置

包括软件质量相关内容、测试策略以及软件配置管理。

### Part 4：项目管理

包括项目管理、过程与项目度量、工作量估算、进度安排和风险分析。

此外，`四种UML图.pdf` 集中介绍课程常用 UML 图，`review2024.pdf` 用于期末范围梳理。

## 作业

`作业/` 保存两次课程作业，每次由需求或任务文档、作业报告及 Draw.io 建模文件组成。Draw.io 文件便于继续编辑 UML 或业务模型，PDF、Word 文档用于查看完整分析过程。

## 课程实验

实验围绕二手交易平台开展，当前包含：

- 2024 年课程设计说明；
- 课程实验报告；
- 结课展示 PPT；
- 系统功能演示视频。

这些材料展示了从需求分析、系统设计到成果汇报的完整课程设计过程，可与需求工程、UML、架构设计和项目管理课件结合阅读。

## 往年试题

`往年试题参考/` 当前包含：

- 2014—2015 学年试卷整理；
- 2016—2017 学年试卷及回忆版；
- 汇总 2012、2014 年内容的历年试题回忆；
- 一份软件工程导论题库。

往年试题常涉及软件过程、需求与 UML、设计原则和模式、测试方法及项目管理。不同年份试卷之间可能存在相似题目，建议在理解概念的基础上归纳题型。

## 建议

1. 阅读课程概览及 Part 0、Part 1，建立软件生命周期和过程模型框架。
2. 学习需求工程和 UML，并结合两次作业完成建模练习。
3. 学习设计概念、架构、构件和界面设计，再对照课程实验理解综合应用。
4. 学习测试、配置管理和项目管理，整理易混淆概念与方法。
5. 使用 `review2024.pdf` 和复习资料查漏，再完成较新的往年试题。

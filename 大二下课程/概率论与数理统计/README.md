## 建议

1. 先通过课件回顾基本概念、常用分布和重要定理。
2. 阅读 `2023复习（秋）.pdf`，按典型题型整理常用方法。
3. 从 22-23、21-22 等较新学年的成套试卷开始限时练习。
4. 对照答案订正后，再查看笔记版，区分正式答案与个人批注。
5. 使用较早学年的图片试卷补充题型，并记录不同解法。

## 说明

- “答案”和“笔记版”不一定是官方材料，可能包含个人解答、批注或扫描内容。
- 个别学期只有试卷或答案，目录结构用于保留其真实完整度，并不表示文件缺失。
- 不同学年的课程范围和题型可能变化，请以当学期教学要求为准。
- 概率论的期末考试比较模板化，把能找到的和老师给的卷子刷透刷懂，满绩不是问题。

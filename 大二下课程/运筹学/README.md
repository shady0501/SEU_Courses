# 运筹学课程资料

本目录收录运筹学课程的课件、参考教材、复习资料及第 1—14 次作业。课程内容包括线性规划、单纯形法、对偶理论、灵敏度分析、运输问题、目标规划、整数规划、动态规划、图与网络优化和对策论。

## 作业

`作业/` 保存第 1—14 次作业。大多数编号包含三类文件：

- 作业题目或任务文档；
- 作业报告；
- 参考答案。

建议按编号依次练习。线性规划、单纯形表、对偶与灵敏度分析等内容前后关联较强，跳过前置作业可能影响后续理解。

## 复习资料

- `第十章-复习.pptx`：用于课程后期或期末知识点回顾。
- `习题集锦.pptx`：汇总典型题型，可配合作业答案进行专题训练。

## 建议学习顺序

1. 从实际问题中练习定义决策变量、目标函数和约束条件。
2. 学习线性规划图解法和单纯形法，熟练完成单纯形表迭代。
3. 理解原问题与对偶问题的关系，再进行灵敏度分析。
4. 依次学习运输、目标规划和整数规划，比较不同模型的适用条件。
5. 学习动态规划、图与网络优化及对策论，整理各类问题的状态或网络表示。
6. 按作业编号复盘计算过程，最后使用习题集锦进行综合练习。

## 使用说明

- 作业答案和报告适合用于订正，建议先独立计算后再查看。
- 课件和作业版本可能对应不同教学进度，遇到符号或方法差异时应以当学期要求为准。
- 部分教材文件较大，GitHub 在线预览失败时可下载后使用本地 PDF 阅读器打开。
- 当时是半开卷期末考试，可以将重点内容抄在一张 A4 纸上带进去，考的也比较简单，如果认真做过作业的话拿九十多分没什么问题。

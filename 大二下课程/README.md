## 课程简介

### 概率论与数理统计

资料以典型题和往年试卷为主。试题覆盖 2017—2018 至 2023—2024 学年的多个学期，已按“学年—学期—资料类型”统一命名，便于成套训练。

### 操作系统

课程围绕进程、线程、调度、同步、死锁、内存和存储系统展开。实验包含 Reverse、xv6 系统调用和虚拟内存主题，可将课件中的机制与系统源码结合理解。

### 算法设计与分析

课程涵盖复杂度分析、分治、动态规划、贪心、搜索及 NP 完全性。目录同时保留课件、作业源文件与批改版、八次上机实验和复习材料，适合按专题完整学习。

### 软件工程导论

课程覆盖软件过程、需求、分析设计、架构、测试、配置管理和项目管理。二手交易平台课程设计保存了任务、报告、展示与视频，可用于观察完整的软件工程交付过程。

### 运筹学

资料涵盖线性规划、单纯形法、对偶、运输、整数规划、动态规划及网络优化等内容。第 1—14 次作业大多包含题目、报告和答案，是当前主要练习来源。

### 思想政治理论课程

两门课程均保存复习范围和考核参考。建议以课程理论框架为主线，将题目要点与正式教材相互核对。

## 建议

1. 先从课程总览确定资料范围，再进入对应课程 README 查看具体说明。
2. 理论课程可按照“课件或教材—作业或实验—复习资料—往年试题”的顺序使用。
3. 操作系统、算法设计与分析和软件工程导论应将实现过程、报告与理论内容结合阅读。
4. 往年试题、个人笔记和参考答案可能存在错误或已不适用于当前教学安排，应结合正式课件核对。
5. 部分教材、视频和课件体积较大，在线预览失败时可下载后本地打开。

## 系统功能

结合需求、设计、测试和用户手册，系统主要涉及以下功能：

- 用户注册、登录、密码重置、个人信息编辑和账户注销；
- 输入文本检索相关图片；
- 输入图片进行跨模态检索；
- 查看图片检索和文本检索的历史记录；
- 对检索结果进行排序；
- 智能问答、常见问题解答及意见反馈；
- 用户界面个性化设置；
- 管理员用户管理、系统管理和数据库备份。

需求与设计文档还记录了高级检索、结果筛选、自动摘要、个性化推荐等规划功能；其中部分功能在测试方案中标记为废弃或未纳入最终测试，实际功能应以用户手册和最终演示为准。

## 技术架构

### 前端

- Vue 3 和 TypeScript；
- Element Plus 组件库；
- Pinia 状态管理；
- Cookie、HTTP 请求及前后端接口调用；
- 使用 Vite 提供开发与构建环境。

### 后端

- Python 与 Flask；
- RESTful API；
- MySQL 数据持久化；
- 用户、检索历史、反馈、个性化设置和系统备份等服务模块；
- 使用 `mysqldump` 完成数据库备份。

### 检索模型

- Python 与 PyTorch；
- OpenCLIP/CLIP 跨模态特征表示；
- BERT 文本特征提取；
- 将图像和文本映射到共享向量空间后完成相似度检索；
- 通过预先缓存数据集特征提高检索速度。

5. 参考测试方案验证功能，再使用用户手册检查完整操作流程。

- 最终汇报 PPT 体积较大，GitHub 可能无法在线预览，可下载后使用本地 PowerPoint 软件打开。
- 文档中的规划功能与最终实现可能不同，应以测试方案、用户手册和最终演示为准。

# 数据结构课程资料

本目录收录数据结构课程的课件、作业、复习资料及往年真题。课程以 C++ 为主要实现语言，覆盖数组、栈与队列、链表、树、图、排序、散列、AVL 树和 B 树。

## 课程概览

| 项目 | 内容 |
| --- | --- |
| 课程课件 | 11 份，覆盖主要数据结构与算法 |
| 课程作业 | 23 个题目批次，共 37 个核心 CPP、13 份报告和 2 份章节答案 |
| 复习资料 | 复习提纲、知识梳理、习题串讲及专题分析 |
| 往年真题 | 6 份试卷、回忆题和考题预测 |

## 课件内容

| 课件 | 主要内容 |
| --- | --- |
| 1.1 BasicConcepts | 数据结构、抽象数据类型、算法与复杂度 |
| 2.array | 数组、矩阵及相关存储结构 |
| 3.stack&queue | 栈、队列及典型应用 |
| 4.1-2、4.3 | 单链表、顺序与链式结构、多项式和双向链表 |
| 5.tree | 二叉树、遍历、搜索树和堆等树结构 |

| 8.hashing | 散列表、散列函数和冲突处理 |

| 10.0.Btree_all | B 树及相关多路搜索结构 |

## 作业

当前作业构成：

- 37 个 `.cpp`：仅保留核心源代码，不包含 Visual Studio 工程缓存和编译产物；
- 13 份 `_报告.docx`：报告内容；
- `章节参考答案/`：保存第一章和第二章答案。

主要练习覆盖算法复杂度、数组与矩阵、字符串、队列模拟、链表、树、并查集、图遍历、最小生成树、最短路径、拓扑排序、排序和查找等内容。

`往年真题/` 保存 2010—2011、2017—2018、2018—2019 学年试卷，以及 2021—2022 学年回忆版和考题预测。其中部分年份同时包含 A、B 卷。

## 建议

1. 掌握复杂度分析，再学习数组、栈、队列和链表。
2. 学习树与搜索结构，重点练习遍历、插入、删除和结构调整。
3. 学习图的表示、DFS、BFS、最小生成树、最短路径和拓扑排序。
4. 比较各种排序和散列方法的时间、空间及适用场景。
5. 将每章课件与对应 `DS2023` 作业批次结合，独立运行和分析源码。
6. 使用复习提纲和习题串讲查漏，再完成往年试卷。

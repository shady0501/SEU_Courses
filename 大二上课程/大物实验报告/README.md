# 大学物理实验资料

本目录按实验项目收录大学物理实验的报告照片、数据记录和实验现象图片，共包含 30 个实验项目、700 余张图片，并附有一份半导体热敏电阻仿真实验讲义。

## 资料概览

| 项目 | 内容 |
| --- | --- |
| 实验数量 | 30 个项目目录 |
| 文件形式 | 主要为 JPG 图片，另有 1 份 PDF 实验讲义 |
| 主要方向 | 力学与振动、电磁学、光学、近代物理及计算机仿真 |

## 目录特点

每个实验使用独立文件夹，图片通常按拍摄或扫描顺序编号，可能包括：

- 实验原理、仪器结构和操作步骤；
- 原始数据、数据处理过程和结果表格；
- 实验曲线、误差分析及思考题；
- 仪器读数或实验现象照片；
- 完整报告的逐页扫描图。

## 建议查看方式

1. 根据当前实验名称进入对应目录。
2. 按文件名或图片时间顺序查看，先确认实验原理和数据页。
3. 使用原始数据独立完成计算，再对照报告中的处理过程。
4. 对图像中的有效数字、单位和不确定度进行复核，不直接照搬扫描结果。

## 使用说明

- 不同学期的仪器型号、数据处理方法和报告格式可能不同，请以当次实验要求为准。
- 图片数量较多且体积较大，GitHub 在线加载较慢时可下载对应项目后查看。

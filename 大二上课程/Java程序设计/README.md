# Java 程序设计课程资料

本目录收录 Java 程序设计课程的课件、课程作业及复习资料。课程从 Java 语言基础和面向对象编程出发，进一步介绍异常处理、文件 I/O、集合、多线程、JDBC 和网络编程。

## 课程概览

| 项目 | 内容 |
| --- | --- |
| 课程课件 | 导论及 10 个主题文件 |
| 编程作业 | Homework04、05、08、10、11，共 5 组 Eclipse 工程 |
| 复习资料 | Java 复习参考及考试内容说明 |

## 课程作业

### Homework04：文件 I/O

包含文件过滤、学生数据读写和运行入口等 Java 源文件，对应 `L04HomeWork.pdf`。

### HomeWork05：集合

使用 `HashMap` 和学生对象完成数据组织，目录中还保存 `student.dat`，对应 `L05HomeWork.pdf`。

### HomeWork08：多线程

保存多线程练习程序，对应 `L08HomeWork.pdf`。

### HomeWork10：JDBC

保存书店数据库访问程序及 MySQL Connector/J 驱动，对应 `L10HomeWork.pdf`。复现时需要根据本地数据库调整连接地址、账号和数据表。

### HomeWork11：网络编程

包含客户端、服务器端和多线程服务器相关源文件，对应 `L11HomeWork.pdf`。

各工程同时保留 Eclipse 配置、`src/` 源文件和 `bin/` 编译结果。阅读代码时应优先查看 `src/`；`.class` 文件和 Eclipse 工程缓存仅用于还原当时的开发环境。

## 建议

1. 学习 Java 基础与面向对象知识，熟悉类、继承、接口和多态。
2. 掌握异常处理和文件 I/O，完成 Homework04。
3. 学习集合框架并完成 HomeWork05。
4. 学习线程创建、同步及并发基础，完成 HomeWork08。
5. 配置数据库和 JDBC 驱动，完成 HomeWork10。
6. 学习 Socket 和多线程服务器，完成 HomeWork11。
7. 最后使用复习资料核对考试范围和常见知识点。

## 说明

- JDBC 作业依赖 MySQL 环境和相应数据库结构，直接运行前需要检查连接配置。
- 网络作业需要分别启动服务器端和客户端。
- 课程安排和考试范围可能调整，请以当学期要求为准。
- 将知识点整理出来背诵一下，最好背背多线程、JDBC、网络编程之类的代码，印象中最后两道大题是要手写代码的……

## 建议

1. 熟练掌握复数的代数形式、极坐标形式及基本运算。
2. 理解解析函数与柯西—黎曼条件，练习解析性判定。
3. 学习复积分和柯西积分公式，形成常用积分计算方法。
4. 掌握泰勒与洛朗展开，能够判断收敛环域。
5. 学习孤立奇点分类和留数计算，并用于复积分及实积分。
6. 最后学习共形映射，使用较新的成套试卷综合练习。

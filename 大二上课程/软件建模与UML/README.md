## 课程作业

### 第一次作业：UML 工具

包含工具使用实验说明和任务文档，用于熟悉建模软件及基本操作。

### 第二次作业：用例建模

保存案例分析、团队实验、点评以及人力资源、图书馆、科研项目、校园信息平台、医院预约和网球场预订等案例。

### 第三次作业：类图建模

包含实验说明、团队任务、点评及多组类图 PNG，适合对照用例模型检查领域对象和关系。

### 第四次作业：活动图建模

包含个人与团队案例、实验点评以及多个系统的活动图。

### 第五次作业：状态机图建模

包含实验说明、团队任务、点评及图书、人员、项目、会员、患者和网球场等对象的状态机图。

## 复习与往年资料

`复习资料/` 可用于梳理各类 UML 图的用途、元素和建模规则。`往年真题/` 中部分文件使用“软件工程”课程名称，内容范围可能比本课程更广，复习时应优先选择 UML、需求分析和建模相关题目。

## 建议

1. 了解 UML、RUP 及模型在软件生命周期中的作用。
2. 从用例图开始描述系统需求和边界。
3. 使用类图建立静态领域模型，再用对象图验证实例关系。
4. 使用活动图描述业务流程，使用状态机图描述单个对象的生命周期。
5. 学习交互图，将用例场景细化为对象之间的消息。
6. 最后学习构件图和部署图，理解设计模型到实现结构的映射。
7. 结合五次作业和往年题检查模型的一致性。

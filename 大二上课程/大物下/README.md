# 大学物理（B）课程资料

本目录收录大学物理（B）课程的课件、作业、习题资料、复习资料及往年考题。2023 年教学资料覆盖振动与波动、波动光学、气体动理论、热力学和量子物理。

## 课件内容

| 模块 | 主要内容 |
| --- | --- |
| 振动 | 简谐运动的运动学与动力学、振动合成、阻尼和受迫振动 |
| 波动 | 简谐波、波的能量、波的叠加、驻波和多普勒效应 |
| 波动光学 | 相干光、双缝干涉、分振幅干涉、迈克尔逊干涉、衍射光栅和偏振 |
| 气体动理论 | 理想气体、经典统计分布和输运理论 |
| 热力学 | 热力学第一定律、多方过程、循环、第二定律和熵 |
| 量子物理 | 光的粒子性、粒子波动性、不确定关系、量子力学简介和原子结构 |

## 作业与习题

- `作业一振动.pdf`：振动专题作业。
- `作业三干涉.pdf`：光的干涉专题作业。

## 往年考题与复习

`往年考题资料/` 保存大学物理 B1、B2 模拟卷及答案、2022 年模拟试卷、期中讲解、月考自测和真题参考。`复习资料/复习.pdf` 可用于期末阶段的整体回顾。

## 建议

1. 按教学日历依次学习振动、波动和波动光学。
2. 完成对应作业和章节习题，注意画图、单位及符号约定。
3. 学习气体动理论和热力学，整理状态量、过程量及常用公式的适用条件。
4. 学习量子物理，重点理解实验事实、基本关系和典型计算。
5. 使用复习资料建立公式体系，再限时完成模拟卷和真题。

## 说明

- 往年试题和题库答案可能对应不同教学范围，应结合教学日历和课件选用。
- 公式使用前应确认物理模型、近似条件和单位制。
- 课程进度及考核方式可能调整，请以当学期安排为准。
- 毕竟是应试，还是多刷题，多背公式。

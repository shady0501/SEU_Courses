## 课程内容

课程资料按七章组织，主要包括：

- 计算机系统的层次结构、性能指标和基本组成；
- 数据与信息的表示、运算方法及运算器；
- 存储器层次结构、Cache 和主存组织；
- 指令系统、寻址方式及程序执行；
- CPU 数据通路、控制器和指令周期；
- 总线结构、仲裁与数据传输；
- 输入输出系统、中断和 DMA。

`计算机组成原理PPT习题.pptx` 可与各章课件配合使用；教学日历用于确认 2023—2024 学年的进度安排。

## 建议

1. 建立计算机系统总体结构，熟悉常用性能指标。
2. 学习数据表示和运算，再进入存储系统。
3. 将指令系统、数据通路和控制器结合起来理解完整指令周期。
4. 学习总线与 I/O，梳理程序查询、中断和 DMA 的差异。
5. 按实验讲义完成实践，将波形或运行结果与理论过程对应。
6. 使用思考题和近年期中、期末试卷进行综合复习。

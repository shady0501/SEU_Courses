## 资料说明

`往年试题资料/` 中的 2022—2023 学年期末考查可用于了解当时的考核形式，另外两份题目资料可作为补充练习。

## 建议

1. 根据教材目录建立课程整体知识框架。
2. 使用期末复习课件核对重点概念及其相互关系。
3. 完成 2022—2023 学年期末考查，练习用规范概念分析材料。
4. 使用其余题目补充练习，并回到教材核对表述。

## 说明

- 往年考查不能代表当前固定题型或范围。
- 理论概念和规范表述应以正式教材及当学期课程资料为准。
- 开卷考试，建议多多熟悉课本，每行字最好都有印象，不然考场上抄都不知道抄什么……

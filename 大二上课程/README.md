## 课程简介

### Java 程序设计

课程从 Java 基础和面向对象编程延伸到异常、I/O、集合、多线程、JDBC 和网络通信。五组作业保留 Java 源码、Eclipse 工程结构和作业说明，可按课件专题依次实践。

### 数据结构

课程覆盖数组、栈与队列、链表、树、图、排序、散列、AVL 树和 B 树。作业已经按原始题号组合整理，报告和核心 C++ 代码放在同一批次目录中。

### 计算机组成原理

课程围绕数据表示、存储系统、指令系统、CPU、总线和输入输出展开。资料同时包含课程实验、章节作业答案以及多个学年的期中和期末试题。

### 软件建模与 UML

课程以 UML 和 RUP 为基础，通过五次作业逐步练习建模工具、用例图、类图、活动图和状态机图，后续课件还覆盖交互图、构件图与部署图。

### 复变函数

课程依次介绍复数与复变函数、解析函数、复积分、幂级数、泰勒和洛朗展开、孤立奇点、留数及共形映射。较新的往年试卷带有答案或详细解答。

### 大学物理（B）

资料涵盖振动波动、波动光学、气体动理论、热力学和量子物理，并配有章节习题、作业、模拟卷及真题。

### 大学物理实验

实验资料覆盖力学、电磁学、光学和近代物理，适合按实验名称查找。

### 马克思主义基本原理

当前目录主要保存往年考查。

## 建议

1. 先通过本 README 确认课程和资料范围，再进入课程 README 查看具体说明。
2. 程序设计与专业基础课建议按照“课件—作业或实验—复习资料—往年试题”的顺序学习。
3. 数学和物理课程应先梳理定义、定理与公式条件，再通过章节练习和成套试卷训练。
4. 软件建模作业应重点检查不同 UML 图之间的需求、对象和行为是否一致。
5. 往年试题、报告和参考答案可能对应不同教学年度，应结合当学期课件核对。
6. 大学物理实验图片数量较多，在线预览较慢时可按项目下载后查看。

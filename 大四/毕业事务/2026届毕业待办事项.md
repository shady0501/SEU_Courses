# 东南大学 2026 届毕业待办事项

具体时间、材料、提交方式和办理顺序请以学校及学院最新通知为准。

## 学业完成情况

- [ ] 核对以下课程的选课及成绩：
  - [ ] 社会实践
  - [ ] 文化素质教育实践
  - [ ] 大学生课外研学
  - [ ] 毕业设计
  - [ ] 形势与政策
  - [ ] 劳动教育总学时达到 26 学时

## 毕业信息与其他事项

- [ ] 关注东南大学 2026 届本科优秀毕业生评选
- [ ] 填写毕业生教学质量调查问卷
- [ ] 填写毕业生登记表
- [ ] 领取毕业礼物
- [ ] 核对毕业及学位信息

## 毕业设计归档

- [ ] 核对 2026 届学信网本科毕业设计信息
- [ ] 提交教育部归档终稿，文件命名为 `<学号>.pdf`
- [ ] 在毕业设计系统提交电子版终稿、查重报告及附件，文件命名为 `<学号>-<姓名>-论文终稿`
- [ ] 确认毕业设计系统材料已由学生和指导教师手签，不使用签章中心
- [ ] 提交纸质归档材料：论文终稿、查重报告、附件及规范性检查表
- [ ] 确认纸质归档材料已由学生和指导教师签字，可按通知使用签章中心

## 离校手续

- [ ] 核对档案去向在线表
- [ ] 在 `91job` 平台修改并确认就业信息
- [ ] 在全国去向登记平台确认毕业去向信息
- [ ] 通过网上办事大厅查看毕业离校指南并完成离校登记
- [ ] 完成学校各部门要求的离校事项：
  - [ ] 图书馆还书
  - [ ] 财务处缴清欠款
  - [ ] 保卫处办理户口迁移
  - [ ] 办理党团组织关系转接
  - [ ] 完成就业办要求的毕业去向确认和母校满意度问卷
  - [ ] 完成上述事项后联系学院辅导员确认，并按要求注销学生证
  - [ ] 到宿管部门办理退宿（退宿后仍然不影响围合和宿舍电子锁权限，主要是结清水电费）
  - [ ] 完成资助中心相关事项
  - [ ] 领取毕业证书和学位证书（一般而言最早是毕业典礼当天下午）
  - [ ] 核对档案转递信息

## 户籍迁移办理参考

本节适用于户口已迁入东南大学集体户、毕业后需要迁出的情况。以下流程和材料根据个人办理记录整理（升学类型，其他类型也类似），实际要求请以“南京公安”线上办事指南、学校通知及受理窗口答复为准。

### 本人线下办理（升学）

携带以下材料前往南京市江宁区行政服务中心（江宁市民中心，杨家圩 2 号）办理：

- [ ] 录取通知书
- [ ] 毕业证书
- [ ] 常住人口登记表
- [ ] 身份证

### 线上申报

1. 关注“南京公安”微信公众号。
2. 依次进入“微服务”→“个人应用”（部分版本显示为“户政服务”）→“大中专生户口迁移”。
3. 选择“应届大中专生户口迁出”，点击“在线申报”。
4. 按系统提示完成人脸识别和身份验证。
5. 填写迁移信息并上传所需材料。
6. 选择办事单位并提交申请；审核通过后，按系统或经办单位要求邮寄纸质材料或领取户口迁移证。

#### 线上申报后按要求邮寄材料

- [ ] [毕业大学生户口迁出申请书](<户籍迁移/户口迁移申请书模板.docx>)
- [ ] 身份证正反面照片
- [ ] 本人手持身份证半身照，确保人脸和证件信息无遮挡
- [ ] 毕业证书
- [ ] 录取通知书
- [ ] 学校官网中有关户口迁移地址的说明截图
- [ ] 常住人口登记表

线上申请后如需邮寄材料，应以系统显示或经办人员确认的收件单位、地址和材料要求为准，不要直接依据旧通知寄送。

#### 委托亲属代办材料

- [ ] [毕业大学生户口迁出授权委托书](<户籍迁移/户口迁移委托书模板.docx>)，写明委托人和受托人的姓名、身份证号码、真实亲属关系、委托事项及迁移地址，并签字
- [ ] 委托人身份证正反面照片
- [ ] 委托人手持身份证半身照，确保人脸和证件信息无遮挡
- [ ] 委托人手持授权委托书和身份证的照片打印件
- [ ] 毕业证书
- [ ] 录取通知书
- [ ] 学校官网中有关户口迁移地址的说明截图打印件
- [ ] 常住人口登记表
- [ ] 受托人按窗口要求携带本人有效身份证件及其他证明材料

> 委托代办必须如实填写身份、亲属关系和委托事项，不得冒充亲属或提交虚假材料。受理范围及亲属关系证明要求请提前向公安机关确认。

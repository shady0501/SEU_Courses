## 课程简介

### 编译原理

课程资料覆盖编译器结构、编程语言基础、词法分析、语法分析、语义规则、中间代码生成、运行时环境和机器无关优化。课程实验保存了一个 C++ 词法分析器和一个 LR(1) 语法分析器，以及相应测试输入、输出结果和实验报告。

适合按照“基础课件 → 词法分析实验 → 语法分析实验 → 编译后端知识 → 历年试题”的顺序学习。

### 数据库原理

课程从数据模型、关系代数和 SQL 开始，进一步介绍 DBMS 架构、查询优化、事务与并发控制、数据库恢复、安全与完整性约束，以及函数依赖、范式和数据库设计。

实验目录包含 10 道 MusicBrainz 数据集 SQL 查询题；往年试题按学年、测验和题型分类，另有 SQL 专项练习，适合用于系统复习和考前训练。

### 软件设计与体系结构

课程重点包括软件架构概念与模型、常见架构风格、质量属性、架构测试与评估，以及架构演化、重构、技术债和坏味道。三项实验分别涉及开源商城项目架构恢复、农事通系统架构设计与 ATAM 评估，以及 KWIC 的多种架构风格实现。

该目录资料较完整，可将课件中的理论与实验中的实际架构案例结合阅读。

### 操作系统专题实践

实践以 RISC-V 架构上的 xv6 教学操作系统为主，涉及实验环境搭建、系统启动、内核初始化、0 号进程、系统调用和中断处理。目录中保存任务说明、课堂板书、带截图的实践过程记录和结课展示。

复现实验前应准备 Ubuntu、RISC-V 交叉编译工具链、QEMU 和 GNU Make，并注意不同版本之间的兼容性。

### 数据结构与算法专题实践

课程围绕无法完全装入内存的大规模数据排序展开，内容包括文件 I/O、缓冲区管理、初始有序顺串生成、二路归并、败者树、最佳归并树和并行 K 路归并。

当前目录主要保存课程资料、实验报告和期末展示，源代码收录在实验报告附录中，没有单独整理为 C++ 工程。

## 使用建议

1. 先通过本 README 确认课程和资料范围，再进入对应课程 README 查看具体文件说明。
2. 理论课程可优先阅读课件和复习提纲，再使用往年试题检验掌握情况。
3. 实践课程建议先阅读任务说明和环境要求，再结合实验报告、过程记录与展示材料复现。
4. 往年试题、手写答案和民间答案可能存在错误或已不适用于当前教学安排，应结合课件核对。
5. 部分文档体积较大，在线预览失败时可下载后使用本地 PDF 或 Office 软件打开。

## 实践内容

### 实验一：基于二路归并的外排序

针对无法完整装入内存的大型整数文件，实现基本外部排序流程：

1. 根据模拟内存大小将原始文件分块。
2. 对各数据块进行内部排序，生成初始有序顺串。
3. 设置两个输入缓冲区和一个输出缓冲区。
4. 对初始顺串执行多轮二路归并。
5. 统计文件读写过程中的 I/O 次数并输出最终排序文件。

报告将程序划分为主程序、外部排序、缓冲区和文件处理等模块，重点分析内存大小、缓冲区大小及块大小对排序流程的影响。

### 实验二：败者树与最佳二路归并

在基本外排序的基础上改进初始顺串生成和归并策略：

- 使用败者树生成尽可能长的变长初始顺串；
- 使用输入、交互和输出缓冲区管理数据流；
- 使用哈夫曼树构造最佳归并树，优先合并较短顺串；
- 将文件读取、顺串生成和结果写入分配给不同线程；
- 使用互斥与线程协作机制保证并行处理安全。

### 实验三：并行 K 路归并

进一步实现基于并行策略的 K 路归并外排序：

- 为多个归并顺串建立输入缓冲队列；
- 使用败者树快速选取当前最小元素；
- 动态管理输入缓冲区和双输出缓冲区；
- 协调磁盘读取、内存归并和磁盘写入；
- 完成初始化、`kWayMerge` 与多顺串归并控制逻辑。

## 建议学习顺序

1. 阅读 `01.Introduction.pptx`，了解课程安排、先修要求和提交规范。
2. 学习 `02.Project.1.External Sorting.pptx`，掌握外排序和磁盘 I/O 的基本模型。
3. 按实验一至实验三的顺序阅读实验报告，理解算法由二路归并向败者树和并行 K 路归并的演进。
4. 查看期末展示，快速回顾实验二的核心方案和实现重点。
5. 若需要复现实验，从报告附录提取代码后补充独立工程、测试数据和性能对比脚本。

## 实验环境

课程任务说明中使用的主要实验环境包括：

- VMware 虚拟机；
- Ubuntu 22.04 LTS；
- RISC-V 架构及交叉编译工具链；
- QEMU 7.2；
- GCC RISC-V 10.2；
- GNU Make 4.3；

具体版本和安装步骤请以课程任务说明及实践记录为准。

## 实践内容

### 1. xv6 环境配置与启动

- 配置 xv6 所需的编译与模拟运行环境；
- 获取并编译 xv6 源码；
- 使用 QEMU 启动 xv6，验证系统能够正常运行。

### 2. 内核初始化与 Hello 输出

结合以下源码文件分析 xv6 从启动到输出信息的过程：

- `entry.S`：系统入口与启动引导；
- `start.c`：机器模式下的早期初始化；
- `main.c`：内核各子系统初始化；
- `printf.c`：格式化输出；
- `riscv.h`：RISC-V 相关寄存器与操作定义；
- `uart.c`：串口初始化与字符输出。

### 3. xv6 的 0 号进程

实践记录从进程表、调度器、进程选择与切换、多核协调和资源管理等角度分析 0 号进程，并通过添加输出信息观察其调用过程。

### 4. 中断处理

实践围绕 `trap.c`、`trampoline.S` 和 `kernelvec.S` 分析 xv6 的中断与异常处理流程，包括：

- 中断触发与处理入口；
- 用户态和内核态之间的上下文切换；
- 中断处理中的关键数据结构及锁机制；
- 中断返回与上下文恢复；
- 增加测试用系统调用和用户程序，验证新增中断处理逻辑。

### 5. 进程管理

结课展示进一步整理了 `proc.h`、`proc.c`、`swtch.S` 和 `syscall.c` 中的进程数据结构、进程初始化、上下文切换与系统调用机制。

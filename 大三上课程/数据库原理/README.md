# 数据库原理课程资料

本目录收录数据库原理课程的课件、课程实验、复习资料及往年试题参考。课程内容覆盖数据库系统基础、数据模型、关系代数、SQL、数据库管理系统、查询优化、事务管理、安全与完整性约束，以及关系模式设计与规范化。

## 课程概览

| 项目 | 内容 |
| --- | --- |
| 资料学年 | 课件主要来自 2024—2025 学年，试题覆盖多个往年学年 |
| 课程重点 | 关系模型与关系代数、SQL 查询、DBMS 架构、事务与并发控制、恢复、安全与完整性、数据库设计与规范化 |
| 实践内容 | 基于 MusicBrainz 数据集完成 10 道 SQL 查询题，并整理实验报告 |
| 复习资源 | 复习提纲、知识点总结、历年试卷、随堂测验、模拟题及 SQL 专项练习 |

## 建议学习顺序

1. 阅读 `DB_Ch1` 和 `DB_Ch2-1`，掌握数据库系统、数据模型、三级模式和数据独立性。
2. 学习 `DB_Ch2-2`，熟悉选择、投影、连接、除法等关系代数运算。
3. 集中学习 `DB_Ch3-1`—`DB_Ch3-4`，并结合 SQL 专项练习和 `Q1.sql`—`Q10.sql` 熟悉查询写法。
4. 学习 `DB_Ch4-1and2`—`DB_Ch4-4`，理解 DBMS 架构、查询优化、事务、并发控制和恢复。
5. 学习 `DB_Ch5`、`DB_Ch6new`，掌握安全与完整性约束、函数依赖、范式和数据库设计。
6. 使用复习提纲和往年题目汇总进行知识点检查，再完成较新的测验、模拟题和历年试卷。

## 使用说明

- 往年试题中的手写答案、个人解答和民间答案不一定是官方答案，使用时应结合课件核对。
- 不同学年的教学内容和考试题型可能有所调整，请以当学期任课教师要求为准。
- 期末考试为全英文开卷考试，但是感觉也没什么卵用，很难直接从课本上找到答案，还是得把课本上每一个知识点都弄清楚为佳，以及多练习 SQL 语法，没记错的话期末光这一块就 40 多分了。

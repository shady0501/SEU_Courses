# 软件设计与体系结构课程资料

本目录收录软件设计与体系结构课程的课件、作业、课程实验、复习总结及往年试题。课程主要讨论软件架构的基本概念、架构建模与风格、质量评估、测试、演化维护、重构、技术债、架构坏味道和软件脆弱性。

## 课程概览

| 项目 | 内容 |
| --- | --- |
| 资料学年 | 主要为 2024—2025 学年，另含往年试题 |
| 课程重点 | 架构建模、架构风格、质量属性、架构评估与演化维护 |
| 实践内容 | 开源项目架构逆向分析、系统架构对比分析、KWIC 多架构实现 |

## 建议学习顺序

1. 阅读 `Unit0`—`Unit3`，理解软件架构的基本概念和建模方法。
2. 集中学习 `Unit4-1`—`Unit4-7`，比较不同架构风格的组件、连接件、约束及适用场景。
3. 学习 `Unit6`、`Unit8` 和 `Unit9`，掌握敏捷架构、建模方法与质量属性。
4. 学习 `Unit10`—`Unit18`，建立架构测试、评估、演化和治理的完整知识体系。
5. 按实验一至实验三查看实际案例，将架构恢复、方案设计、质量评估和代码实现结合起来。
6. 最后使用复习总结、作业和往年试题进行查漏补缺。
7. SA 背就完了，把画的重点总结总结，和其他人对照一下，必要时问问老师，然后开背，背多分（）；以及 SA 比较主观，建议多和老师交流，多问问老师（）

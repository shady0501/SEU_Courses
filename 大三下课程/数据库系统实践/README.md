## 结业考核

[数据库结业考核.docx](<结业考核/数据库结业考核.docx>) 记录了结业考核的操作过程及结果截图，主要包含：

1. 手工创建数据库并验证创建结果。
2. 创建数据字典视图和 Oracle 内部包。
3. 创建 `SCOTT` 与 `HR` 方案。
4. 编写和执行相关 SQL 语句。
5. 使用 RMAN 进行数据库整库备份。
6. 删除 `SCOTT.EMP` 表后，使用 LogMiner 查询删除操作发生的时间。
7. 进行基于时间点的数据库恢复，将 `SCOTT.EMP` 表恢复出来。
8. 添加数据库补充日志，并通过版本查询与闪回事务查询获得事务号和 `UNDO SQL`。

## 建议

1. 按第一次至第六次的顺序查看 `作业/` 中的操作截图，回顾课程实践过程。
2. 阅读 `结业考核/数据库结业考核.docx`，重点复习数据库创建、方案配置和 SQL 操作。
3. 最后复习 RMAN 备份恢复、LogMiner 日志挖掘及 Oracle 闪回相关操作。
4. 数据库系统实践课后有作业，而且还需要期末随堂考试，需要磁盘 200G 空闲大小，以及安装虚拟机和操作 Oracle，建议能选更好的实践课还是选其他的吧。

# 大三下课程

本目录整理东南大学软件工程专业大三下学期的课程资料，目前包含软件质量保障和数据库系统实践两门课程。

## 课程概览

| 课程 | 任课老师 | 资料内容 | 备注 | 详细说明 |
| --- | --- | --- | --- | --- |
| 软件质量保障 | lbx | 课程课件、分学年复习资料、期末复习笔记、随堂测试及考试题型回忆 | 当年唯一指定教师，给分其实挺高的 | [查看课程 README](<软件质量保障/README.md>) |
| 数据库系统实践 | hwj、lzw | 第 1—6 次作业截图，以及涉及 Oracle 数据库创建、备份恢复、LogMiner 和闪回查询的结业考核文档 | 有更好的就选其他实践课吧 | [查看课程 README](<数据库系统实践/README.md>) |

## 使用说明

- 各课程目录下的 `README.md` 提供完整文件清单、内容简介和建议查看顺序。
- 课程资料仅供学习与复习参考，请以任课教师发布的最新要求为准。
- 文档、课件及作业截图的版权归原作者所有，请勿用于商业用途。

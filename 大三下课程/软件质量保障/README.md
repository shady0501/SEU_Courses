# 软件质量保障课程资料

本目录收录软件质量保障（SQA）课程的课件与复习资料，内容涵盖软件缺陷检测、软件测试基础、黑盒测试、白盒测试、回归测试、软件架构及性能测试等主题。

## 目录概览

```text
软件质量保障/
├── 课件/                  # 课程教学课件，共 7 份 PDF
└── 复习资料/
    ├── 22-23/             # 2022—2023 学年复习笔记、试题回忆及配图
    └── 24-25/             # 2024—2025 学年分章资料、期末复习和随堂测试
```

## 建议

1. 先按文件编号阅读 `课件/`，建立完整的课程知识框架。
2. 使用 `复习资料/24-25/SQA Ch1-Ch7.pdf` 按章节复习。
3. 结合 `复习资料/22-23/SQA Review.md` 查阅详细知识点和示例。
4. 最后通过随堂测试与 `exam.md` 熟悉题型并查漏补缺。
5. 当年期末选填主要是随堂测试为主，大题会涉及其他内容，最好是将复习资料应背尽背吧。
